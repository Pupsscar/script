# Какие скрипты заменить в Roblox Studio

Замените в Studio **весь код** этих трёх скриптов (Ctrl+A → вставить). Остальные скрипты из `Systems.rbxm` не менялись.

| Файл здесь | Скрипт в Studio | Где лежит |
|---|---|---|
| `Monsters.server.lua` | **Monsters** (Script) | там же, где был (ServerScriptService) |
| `FallDamageController.module.lua` | **FallDamageController** (ModuleScript) | ReplicatedStorage → Modules |
| `MonsterData.module.lua` | **MonsterData** (ModuleScript) | ReplicatedStorage → Modules |

## Что изменено

**Скин-волкер (B-414)**
- Появляется без кожи: светло-серое тело без одежды и волос, жуткое лицо (пустые глазницы разного размера, светящиеся точки-зрачки, тёмные подтёки, растянутая улыбка с зубами).
- Кожу надевает только после убийства: съедает тело, прячется и возвращается в облике жертвы.
- При разоблачении снимает кожу полностью: лицо игрока больше не остаётся.
- В маскировке не пишет в чат, не печатает и не издаёт звуков. Звуки только когда показывает себя.
- В маскировке повторяет движения игрока: идёт, когда вы идёте, стоит, когда вы стоите, прыгает, когда вы прыгаете.
- Теперь догоняет и бьёт: упреждает, куда вы бежите, делает рывок при ударе, у него чуть больше дальность удара, сервер держит физику тела.

**Чёрная сущность (D-130)**
- Если подойти к ней вплотную (около 7 стадов), сразу атакует.

**ИИ монстров (оба)**
- Новый поиск пути: идут напрямую, если путь свободен, иначе по PathfindingService (путь считается в фоне, обходит препятствия, умеет запрыгивать на уступы).
- Больше не прыгают бездумно под игроком: прыгают только на точках прыжка пути или перед низким препятствием. Если вы стоите там, куда не добраться, монстр ждёт рядом, а D-130 через несколько секунд отходит наблюдать.
- Если застряли, пересчитывают путь и обходят препятствие сбоку.

**Сломанная нога**
- Исправлен полёт: болтающаяся сломанная конечность больше не сталкивается с полом и не подбрасывает персонажа.
