# Marrow Animator 1.0.0

Плагин для Roblox Studio. Анимирует по ключевым кадрам на одном таймлайне:

- риги на Motor6D (R6, R15, монстры, оружие);
- свойства любых объектов;
- камеру.

## Файлы

| Файл | Зачем |
|---|---|
| `MarrowAnimator.lua` | сам плагин, кладётся в папку Plugins |
| `MarrowAnimator.rbxmx` | тот же плагин внутри Script, нужен для «Save as Local Plugin» и «Publish as Plugin» |
| `MarrowAnimatorIcon.png` | иконка 512×512 для кнопки и страницы в Creator Store |

## Установка у себя

**Вариант A (проще всего):**
1. В Studio открой вкладку **Plugins** и нажми **Plugins Folder**.
2. Скопируй туда `MarrowAnimator.lua`.
3. Перезапусти Studio.

На вкладке Plugins появится кнопка **Marrow Animator**.

**Вариант B:**
1. Перетащи `MarrowAnimator.rbxmx` в окно Studio, появится Script `MarrowAnimator`.
2. Нажми на нём ПКМ и выбери **Save as Local Plugin…**
3. Скрипт из места потом удали. Даже если забудешь, в игре он ничего не сделает: без `plugin` он сразу выходит.

**Иконка на кнопке (по желанию):**
1. Загрузи `MarrowAnimatorIcon.png` как картинку: Asset Manager в Studio или Creator Dashboard.
2. Впиши её ID в самом верху файла: `local ICON = "rbxassetid://…"`.

## Публикация в Creator Store

1. Перетащи `MarrowAnimator.rbxmx` в Studio, нажми ПКМ на скрипте и выбери **Publish as Plugin…**
2. Укажи название, описание и иконку (`MarrowAnimatorIcon.png`).
3. Открой плагин на Creator Dashboard и включи распространение в Creator Store.
4. Чтобы обновить плагин, снова выбери **Publish as Plugin** и замени уже опубликованный.

Можно ли на этом заработать, разобрано в конце файла.

## Быстрый старт

1. Нажми кнопку **Marrow Animator**, окно откроется снизу.
2. Выдели риг: модель с Motor6D, например манекен из Avatar → Rig Builder. Нажми **+ New**.
3. Включи **POSE** (клавиша `P`) и кликни часть тела во вьюпорте:
   - кольца (`R`) поворачивают её;
   - стрелки (`G`) двигают её.
4. Пока включён **Auto-key**, каждое изменение сразу записывается ключом на текущем кадре.
5. Кликни по линейке с кадрами, чтобы перейти на другой кадр, и поставь следующую позу.
6. Выдели ключи и справа в инспекторе выбери сглаживание: стиль, направление или готовый пресет.
7. `Space` проигрывает анимацию.
8. Когда готово: **Export → KeyframeSequence** или **Publish**.

## Возможности

### Позинг
- Поворот и перемещение частей прямо во вьюпорте, в локальных или мировых осях.
- Привязка к углу и расстоянию.
- Числовой ввод поворота и смещения.

### Таймлайн
- Зум: `Ctrl` + колесо.
- Прокрутка: `Shift` + колесо или средняя кнопка мыши.
- Ключи:
  - выделение рамкой;
  - перетаскивание по времени, с `Ctrl` создаётся копия;
  - двойной клик ставит ключ;
  - правый клик открывает меню.
- Строка «All keys» двигает целые позы.

### Сглаживание
- 12 стилей × 3 направления на каждый ключ, с живой кривой и 10 пресетами.
- При экспорте кривые запекаются, поэтому в игре анимация идёт кадр в кадр как в превью. Это проверено тестом.

### Визуализация
- Луковая кожа: призраки соседних поз (`O`).
- Траектория выбранной части (`T`).
- Просмотр через анимированную камеру.

### Позы
- Копировать и вставлять ключи и целые позы.
- Зеркалить позу лево ↔ право (`M`) и вставлять зеркально.
- Сброс в позу покоя.
- Библиотека поз: сохраняется в плейсе и применяется к любому ригу с такими же именами частей.

### События, свойства, камера
- События становятся KeyframeMarker. В игре: `track:GetMarkerReachedSignal("Имя")`.
- Дорожки свойств: свет, части, модели (Pivot), GUI, звук, частицы, эффекты Lighting и любое свойство по имени.
- Камера: позиция и угол обзора.

### Импорт и экспорт
- Импорт из KeyframeSequence, из сохранённых в `RBX_ANIMSAVES` или по ID анимации (своей или своей группы).
- Экспорт в KeyframeSequence в `ServerStorage > RBX_ANIMSAVES`, его открывает и встроенный Animation Editor.
- Публикация в Roblox одной кнопкой.

### Катсцены без загрузки
**Export → Cutscene ModuleScript** собирает модуль, который проигрывает в игре:
- суставы (через `Motor6D.Transform`);
- свойства;
- камеру;
- события.

Загружать анимацию в Roblox для этого не нужно.

### Инструменты
- Вставка и удаление кадров.
- «Замкнуть петлю».
- Реверс, растяжение и сдвиг ключей.
- Смена FPS без потери тайминга.
- Упрощение запечённых анимаций: убирает ключи, которые ничего не меняют.

### Undo/Redo и Team Create
Все изменения отменяются обычным Undo/Redo Studio (`Ctrl+Z` / `Ctrl+Y`). Данные лежат прямо в плейсе, поэтому Team Create видит те же анимации.

Чего пока нет: IK (инверсная кинематика) и вставки персонажей. Это можно добавить в следующих версиях.

## Горячие клавиши

Работают в окне плагина (сначала кликни по таймлайну). Во вьюпорте они работают, пока включён POSE.

| Клавиша | Действие |
|---|---|
| `Space` | play / stop |
| `K` / `Shift+K` | ключ на выбранный сустав или свойство / ключ на все суставы |
| `,` `.` | предыдущий / следующий кадр |
| `[` `]` | предыдущий / следующий ключ |
| `Home` / `End` | первый / последний кадр |
| `P` | режим POSE |
| `R` / `G` | вращение / перемещение |
| `L` | локальные / мировые оси |
| `N` | привязка вкл/выкл |
| `M` | зеркалить позу |
| `O` / `T` | луковая кожа / траектория |
| `F` | показать всю анимацию |
| `Delete` | удалить выбранные ключи |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+A` | копировать / вставить / выбрать все ключи (только в окне плагина) |
| `Esc` | снять выделение / выйти из POSE |

Свои клавиши, которые работают везде в Studio: окно **Customize Shortcuts**, поиск «Marrow». Оно в меню File, в некоторых версиях Studio в File → Advanced.

## Где что лежит

- **`ServerStorage > MarrowAnimations`.** Все анимации и библиотека поз (`_PoseLibrary`). Это обычные объекты: их можно копировать между плейсами.
- **`ServerStorage > RBX_ANIMSAVES > <риг>`.** Экспортированные KeyframeSequence.
- **`ReplicatedStorage > MarrowCutscenes`.** Модули катсцен.
- **Превью.** Позу на риге показывает `Motor6D.Transform`, в файл она не сохраняется. Если Studio его не отображает, плагин сам переходит на C0 и при закрытии возвращает C0 обратно.

## Катсцена в игре

```lua
-- LocalScript
local cutscene = require(game.ReplicatedStorage.MarrowCutscenes["Моя анимация"])
local handle = cutscene.Play({Speed = 1})        -- Loop, Camera = false, KeepCamera, Rig = модель, ResetJoints
handle.MarkerReached:Connect(function(name, value) print(name, value) end)
handle:Wait()                                     -- или handle:Stop()
```

## Насколько это проверено

- Код компилируется Luau без ошибок.
- Прогнано 172 автоматические проверки на имитации API Roblox: R6-риг, ключи, сглаживание, проигрывание, мышь на таймлайне, гизмо, зеркало, экспорт → проигрывание «как движок» → импорт обратно, катсцена, режим C0, горячие клавиши, меню.
- В настоящей Studio плагин ещё не запускался. Сильнее всего от Studio зависят клавиши внутри окна плагина и вид гизмо. Если что-то ведёт себя не так, напиши, и я поправлю.

## Получаю ли я прибыль за использование плагина?

**Бесплатный плагин. Нет.** Roblox не платит автору бесплатного плагина ни за установки, ни за использование: ни деньгами, ни Robux.

**Платный плагин. Да, но только продажей в Creator Store.**

- **Цена** от **$4.99 до $249.99**, только в долларах. Цену в Robux поставить нельзя.
- **Доход:** продавец получает **100% чистой выручки**. Вычитаются только налоги и комиссия платёжной системы.
- **Выплаты:** деньги 30 дней лежат на удержании, потом раз в месяц (1-го числа) уходят на банковский счёт аккаунта продавца.
- **Нужен аккаунт продавца через Stripe:**
  - 18+ лет, или 13–17 лет с согласия родителей;
  - аккаунт Roblox, подтверждённый проверкой возраста или документом;
  - включённая двухэтапная проверка.
- **Страны:** регистрация продавца пока не поддерживается, например, в **Бразилии, Китае, Индии и России**. Из России продавать плагин за деньги через Roblox сейчас нельзя.
